# Страница «Создать в 3D» (интеграция с 3D-конструктором)

Ветка `feature/create-3d` от `b5100a1`. Тестовая версия: опубликованный сайт (`gh-pages`) и существующий сайт компании не изменены.

Полный план интеграции, варианты размещения, решения владельца и шаги Production описаны в репозитории конструктора: `kyrokzai/formiq-configurator`, ветка `feature/vernissage-embed`, файл `docs/VERNISSAGE-INTEGRATION.md`.

## Дизайн: утверждённая светлая версия v9

- Страница свёрстана по v9 («VERNISSAGE 2.0 Visual Design v9», приватный artifact claude.ai `8S9HxPkcAfqMerAJqK4UF3`).
- Использованы:
  - палитра слоновой кости и бронзы;
  - Cormorant Garamond + Manrope;
  - шапка, меню и кнопки v9.
- У страницы свой каркас `src/layouts/V9.astro` и стили `src/styles/v9.css`. Тёмный `global.css` прежней версии не подключается.
- Главная страница не менялась. Перенос главной на v9 — отдельная задача.

## Как устроено

- `/create-3d/`: шапка и меню сайта, затем 3D-конструктор VERNISSAGE во фрейме на всю оставшуюся высоту экрана.
- **Конструктор — отдельный продукт.** Это сборка покупателя на движке FORMIQ: 4 шага, без режима для специалистов и без цен. В этот репозиторий он не копируется; сайт хранит только адрес сборки:
  - `PUBLIC_VN_CONFIGURATOR_URL` при сборке сайта;
  - по умолчанию — Preview `https://formiq-configurator-git-feature-vernissage-embed-kyrokzai.vercel.app/`.
- **Параметры фрейма.** Во фрейм попадают только `start`, `layout` и `finish` (`src/data/create3d.ts`, `frameSrc`). Остальные параметры адреса страницы отбрасываются.
- **Ссылки главной v9 на конструктор:** `createLink(base, start, layout, finish)`; соответствие категорий — `CATEGORY_LINKS`.
- **Запасные варианты.**
  - «Открыть конструктор на весь экран» — внизу страницы и в меню на телефоне.
  - Если фрейм не загрузился за 20 секунд, страница предлагает открыть конструктор отдельно.
- **Раскладка.**
  - Телефон: шапка 60 px, конструктор до низа экрана, страница не прокручивается.
  - Телефон горизонтально: шапка 44 px.

## Проверка

```bash
npm run build      # сборка с адресом Preview
PUBLIC_VN_CONFIGURATOR_URL=http://127.0.0.1:4176/ npx astro build --outDir <папка>   # с локальной сборкой конструктора
```

Браузерная проверка страницы вместе с конструктором лежит в репозитории конструктора: `tests/vernissage-embed-browser.mjs`. Это эмуляция Chromium (компьютер, iPhone вертикально, 844×300, 667×280), а не Safari на настоящем iPhone.
