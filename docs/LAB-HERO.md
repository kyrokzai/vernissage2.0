# Лаборатория: три концепции мобильного первого экрана

Ветка `experiment/cinematic` (локальная). Стабильная сборка `feature/v9-home` не изменена, кредиты Higgsfield не потрачены.

## Задача от владельца

На телефоне первый экран должен:
- сразу показывать интерьер;
- тратить меньше места на текст;
- иметь изящные кнопки;
- содержать кинематографическое видео;
- давать глубину, свет и контраст;
- плавно двигаться при прокрутке, с параллаксом.

## Где посмотреть

На компьютере у этих страниц остаётся первый экран v9.

Видео в прототипе — заглушки, сделанные из реальных фотографий VERNISSAGE:
- медленный проезд камеры;
- тёплая полоса света;
- качающаяся тень листвы;
- бесшовная петля 7 с.

## Что общего у всех трёх

- **Текст.** Вместо надзаголовка, трёх строк заголовка, абзаца и двух подписей — две строки заголовка и одна строка условий. Надзаголовок остался только в C.
- **Кнопки.** «Пилюли» высотой 48 px вместо прямоугольников 56–62 px:
  - тёмная — «Рассчитать стоимость →»;
  - светлая — «◇ 3D».
- **Видео.** Включается, только когда видно. При «уменьшить движение», экономии трафика и в режиме энергосбережения iPhone остаётся неподвижный кадр.
- **Анимации.** Появление при загрузке — на CSS, без ожидания библиотек. Параллакс прокрутки — GSAP ScrollTrigger, анимации следуют за прокруткой без задержки. Прокрутку страница не перехватывает.
- **Нижняя панель** («Рассчитать стоимость · 3D · WhatsApp») появляется, когда кнопки первого экрана уходят вверх, — как в v9.

## A — «Арка-окно» (светлая, развитие v9)

- **Идея.** Интерьер в большой арке на всю ширину — главный мотив v9, только крупнее.
- **Компоновка.** Шапка 60 px → арка с видео (весь экран минус 268 px) → заголовок в две строки → кнопки → одна строка условий.
- **Движение:**
  - при загрузке внутри арки поднимается «занавес» цвета камня, слова заголовка выезжают из маски, кнопки поднимаются;
  - при прокрутке арка стоит на месте, а «камера» внутри неё отстаёт и приближается (параллакс 0→14 %, масштаб 1,10→1,22), подпись «Реальный проект» уходит.
- **Плюсы:** узнаваемо, спокойно, ближе всего к утверждённому v9; меньше всего риска.
- **Минусы:** самая сдержанная из трёх.

## B — «Лента комнат» (первый экран — каталог)

- **Идея.** Человек сразу видит все комнаты и листает их пальцем. Первая карточка — видео кухни.
- **Компоновка.** Шапка → надзаголовок с точками-индикатором → заголовок «Мебель для каждой комнаты — по вашим размерам» → лента арок по 72 % ширины, следующая выглядывает справа → кнопки.
- **Движение:**
  - карточки въезжают справа по очереди;
  - активная карточка «оседает» (масштаб 1,06→1);
  - при прокрутке заголовок уходит быстрее ленты.
- **Плюсы:** больше всего интерьеров на первом экране, сразу ведёт в конструктор по нужной комнате.
- **Минусы:**
  - сливается с разделом «Мебель для каждой комнаты» ниже — его нужно будет заменить или сократить;
  - меньше «кино».

## C — «Вечерняя сцена» (полноэкранное кино, контраст)

- **Идея.** Видео на весь экран, вечерний свет и светлый текст внизу — как первый кадр фильма.
- **Компоновка:**
  - видео 100 % экрана;
  - затемнение сверху (под шапкой) и снизу (под текстом);
  - светлая шапка;
  - надзаголовок, заголовок в три строки, светлая и прозрачная кнопки;
  - бегущая линия «листайте вниз».
- **Движение:**
  - при загрузке видео проявляется из темноты, текст поднимается;
  - при прокрутке первый экран «прилипает», текст уходит вверх и гаснет, видео приближается (1→1,12), ветка переднего плана уходит;
  - следующий раздел наезжает на сцену светлым слоем со скруглением 26 px.
- **Плюсы:** самая кинематографичная и контрастная, сильнее всего отличается от обычных сайтов.
- **Минусы:**
  - тёмный первый экран меняет характер бренда, который в v9 светлый;
  - нужно действительно красивое вечернее видео, заглушка из фото его не заменит.

## Замеры

Chromium, телефон 390×844, 4G, процессор ×4.

| | A | B | C | v9 сейчас |
|---|---|---|---|---|
| LCP (главный блок) | 0,88 с | 0,84 с | 0,70 с | 0,86 с |
| Загружено за первые секунды | 1,09 МБ | 0,70 МБ | 0,95 МБ | 0,37 МБ |
| Прокрутка, кадры/с (95-й процентиль) | 60 (17 мс) | 60 (17 мс) | 61 (17 мс) | 60 |
| CLS | 0 | 0 | 0 | 0 |

- Вес вырос из-за видео: 720×1280, 350–480 КБ.
- В рабочей версии:
  - видео 540×960 с HEVC для Safari (≈ 200–250 КБ);
  - запуск видео только после загрузки первого кадра-постера;
  - скрытый компьютерный первый экран не грузится на телефоне.
- Цель — до 600 КБ до прокрутки.

## Проверено

- WebKit с профилем iPhone 15 Pro и Chromium с профилем iPhone SE (320×568): кнопки на обоих телефонах в первом экране, горизонтальной прокрутки нет.
- Видео играет в обоих браузерах: H.264 и запасной WebM.
- Настоящий iPhone — **не проверен**.
