## 2. Принципы

1. **Прокрутка всегда родная.**
   - Не используем ScrollSmoother и `normalizeScroll`, не перехватываем `wheel` и `touch`.
   - Сцены «прилипают» через CSS `position: sticky`, а не через pin в GSAP: на iOS так стабильнее.
   - `scrub: true` — анимация не «догоняет» прокрутку с запаздыванием.
2. **Анимируются только `transform` и `opacity`.**
   - Никакого живого `filter: blur()` на больших движущихся слоях. Замер показал: оно одно роняет компьютер с 60 до 49 кадров/с.
   - Размытые ветки и тени — заранее отрисованные WebP с прозрачностью.
3. **Первый экран не ждёт эффектов.**
   - Заголовок появляется по словам на чистом CSS.
   - GSAP загружается после `load` и в простое браузера.
   - Кадры сцены начинают грузиться только с первой прокруткой.
4. **Резерв для всех случаев.**
   - Без JavaScript, при «уменьшить движение» или режиме экономии трафика класс `html.cine` не ставится, GSAP не скачивается.
   - Сцена показывает неподвижный кадр и весь текст сразу. Остаётся проверенная v9.
5. **Конструктор не трогаем.**
   - На `/create-3d/` GSAP не загружается.
   - Переход к конструктору — только CSS View Transitions; там, где они не поддерживаются, — обычный переход.
6. **Честность материалов.**
   - Видео «реального проекта» — только настоящая съёмка или движение камеры по настоящей фотографии.
   - ИИ-видео — только для иллюстраций с подписью «Иллюстрация» или для атмосферных слоёв (свет, ветки, текстуры).
   - ИИ не может изображать работы VERNISSAGE.

## 3. Раскадровка

Для каждого эффекта — рассмотренные варианты и выбранный.

### 3.1. Первый экран — «живые тени»

Варианты:
- (а) ИИ-видео-петля всего кадра;
- (б) тень листвы, качающаяся на стене, и ветка переднего плана в расфокусе;
- (в) параллакс фото внутри арки;
- (г) мерцание света на фасаде.

**Выбрано: (б) + (в).**
- Справа сверху свет: тень листвы ложится на стену за текстом и медленно качается, цикл 14 с.
- Ближняя ветка в расфокусе уходит вверх быстрее страницы — это передний план.
- Фото внутри арки сдвигается медленнее страницы, вставка с ручкой — навстречу.
- Покачивание останавливается, когда первый экран не виден.

**Типографика.** Слова заголовка выезжают из маски по очереди (1,15 с, плавное торможение). Это одно оркестрованное появление вместо прежнего общего.

### 3.2. Новая сцена «Через арку» — scroll-driven cinematic video

Варианты:
- (а) полноэкранное видео, привязанное к прокрутке;
- (б) камера проходит сквозь арочный проём в интерьер;
- (в) раскладка комнат как в книге;
- (г) смена дня и ночи в одной кухне;
- (д) сборка кухни по модулям.

**Выбрано: (б).** Арка — сквозной мотив v9: арки категорий, арочный 3D-раздел, арка первого экрана.

Ход сцены:
- Сначала на экране стена со светлым арочным проёмом.
- С прокруткой проём растёт, камера «входит» в комнату.
- Ветка переднего плана уходит влево-вверх.
- Затемнение слева даёт контраст тексту, по очереди появляются три строки:
  1. «Каждый проект начинается с замера.»
  2. «Материал, цвет и свет вы выбираете сами.»
  3. «Остальное мы делаем на заказ — по вашим размерам.»
- В конце раздел «Мебель для каждой комнаты» наезжает на сцену. Без затемнения в пустоту — первая версия давала «пустой экран».

Глубина в кадре:
- стена с проёмом — передний план, масштаб ×5,6;
- ветка — самый ближний план, движется быстрее всех;
- интерьер — дальний план, кадры камеры.

**Видео — покадровая последовательность на `<canvas>`, а не `<video>`.**
- Прокрутка выбирает номер кадра.
- Перемотка `video.currentTime` в Safari на iPhone даёт рывки на ключевых кадрах.

В прототипе вместо видео — 72 кадра (телефон — 48) «движения камеры» по реальной фотографии проекта. С подписью.

### 3.3. Арки категорий — раскрытие фото

Варианты:
- (а) маска-круг;
- (б) «занавес» цвета камня поднимается внутри арки, фото «оседает» из увеличения;
- (в) вырастание арки снизу;
- (г) затемнение.

**Выбрано: (б).**
- Однократно при появлении, с задержкой 0,09 с между арками.
- На телефоне — по всей ленте сразу.
- Наведение и раскрытие арок v9 без изменений.

### 3.4. «Работы» — многослойный параллакс

Варианты:
- (а) три плана: фото, деталь, подпись;
- (б) наклон фото за курсором;
- (в) горизонтальная лента.

**Выбрано: (а).**
- Главное фото внутри рамки ±6 %, на телефоне ±3 %.
- Кадр-деталь — навстречу, ±48 px.
- Курсорные эффекты отложены: на телефоне их нет.

### 3.5. Переходы между разделами

Варианты:
- (а) шторка;
- (б) затемнение в цвет;
- (в) мягкое пятно света сверху справа, плывущее с прокруткой, и строки заголовка из маски;
- (г) «вспышка» линии.

**Выбрано: (в)** — продолжает схему света v9. Подзаголовок появляется вслед за заголовком.

### 3.6. Переход к FORMIQ Configurator

Варианты:
- (а) полноэкранное видео перед загрузкой;
- (б) View Transition: рендер кухни из 3D-раздела «перетекает» в окно конструктора на `/create-3d/`;
- (в) затемнение в цвет фона.

**Выбрано: (б).**
- 0,62 с; работает в Chrome 126+ и Safari 18.2+.
- В остальных браузерах обычный переход, без задержки.
- Сам конструктор не меняется, на его странице одна строка CSS.

**Перед переносом в рабочую версию:** это файлы второй сессии (`src/pages/create-3d/index.astro`, `src/layouts/V9.astro`) — нужно её согласие.

## 7. Технические требования

### Кодирование (ffmpeg)

```bash
# V1 → кадры: компьютер и телефон
ffmpeg -i v1-16x9.mov -vf "fps=12,scale=1600:900:flags=lanczos" -c:v libwebp -quality 62 -compression_level 6 d/%03d.webp
ffmpeg -i v1-9x16.mov -vf "fps=8,scale=540:900:flags=lanczos"  -c:v libwebp -quality 62 -compression_level 6 m/%03d.webp

# V2/V3 → фоновые петли
ffmpeg -i v2.mov -an -vf "scale=1280:-2,fps=25" -c:v libx264 -profile:v high -crf 26 -preset slow -pix_fmt yuv420p -movflags +faststart v2-1280.mp4
ffmpeg -i v2.mov -an -vf "scale=1280:-2,fps=25" -c:v libx265 -tag:v hvc1 -crf 28 -preset slow -pix_fmt yuv420p -movflags +faststart v2-1280-hevc.mp4
```

### Разметка фоновых видео

```html
<video muted playsinline loop preload="none" poster="…">
  <source src="…-hevc.mp4" type='video/mp4; codecs="hvc1"'>
  <source src="….mp4" type="video/mp4">
</video>
```

- Запуск — через IntersectionObserver, только когда видео на экране. Вне экрана — `pause()`.
- Атрибут `autoplay` не ставим.

### Safari на iPhone

- `muted` + `playsinline` обязательны.
- В режиме энергосбережения автозапуск запрещён — остаётся постер. Видео в дизайне только декоративные.
- Не перематываем `<video>` прокруткой — только кадры на `<canvas>`.
- Высота сцен: `100lvh` и `ScrollTrigger.config({ ignoreMobileResize: true })`. Сцены не прыгают при появлении и скрытии адресной строки.
- Не используем `pin`, только CSS `sticky`.
- Память для `<canvas>`:
  - ограничиваем число и размер кадров;
  - проверка на iPhone 12–16;
  - при нехватке памяти — окно кадров вокруг текущего.
- `filter: blur()` и `backdrop-filter` на больших движущихся слоях запрещены: на iPhone это самое дорогое.
- View Transitions между страницами — только с Safari 18.2. На более старых iOS — обычный переход.

### `prefers-reduced-motion` и Save-Data

- Эффекты не включаются, GSAP не скачивается.
- Видео не запускаются, показываются постеры.
- Сцена 3.2 становится обычным блоком с кадром и текстом.

### Резервные статичные изображения

- Постер для каждого видео и сцены: WebP плюс JPEG для старых браузеров через `<picture>`.
- `noscript` не нужен: без JavaScript показывается статичная версия.
