# VERNISSAGE 2.0 — правила для Claude Code (ветка experiment/cinematic)

## Границы

- **Эксперименты только в `experiment/cinematic`.** Не менять `main`, `feature/v9-home`, `feature/create-3d`, рабочий vernissage.kz и FORMIQ Configurator.
- **Платные действия — только с разрешения владельца:**
  - генерация в Higgsfield, в том числе пробная;
  - платные пакеты и сервисы;
  - Figma Dev Mode.
- **Факты.** Не выдумывать цены, отзывы и проекты. ИИ-изображения и ИИ-видео подписывать «Иллюстрация — не работа VERNISSAGE».

## Инструменты: какой и когда

Брать один подходящий инструмент под задачу, а не все сразу. Навыки грузятся в контекст и стоят токенов.

| Задача | Инструмент |
|---|---|
| Направление дизайна новой страницы или блока | `frontend-design` (плагин) **или** `design-taste-frontend` (Taste Skill) — один из них |
| Аудит и шлифовка готового экрана, анти-шаблонность | `impeccable` (`/impeccable audit`, `polish`, `critique`); быстрый автоматический проход — `npx impeccable detect <файл или URL>` |
| Микровзаимодействия, нажатия, переходы | `emil-design-eng`; жесты, физика, материалы — `apple-design` |
| Проверка анимаций перед показом | `review-animations`; провалы кадров — `animation-performance` |
| Scroll-анимации, закрепление, scrub | `gsap-scrolltrigger` (+ `gsap-timeline`, `gsap-performance`); SplitText, Flip — `gsap-plugins` |
| Ролик, моушн-видео, кинетическая типографика | `vizavi-motion` |
| Разбор видео-референса | `watch` (локально: кадры через ffmpeg; Gemini — только с согласия, видео уходит в Google) |
| Кинематографический контент | Higgsfield MCP — сначала `estimate_*_cost`, генерация только после разрешения |
| Визуальная проверка в браузере | Playwright MCP (снимки — в `/home/user/.playwright-mcp`) или Node Playwright (`tests/v9/*.cjs`); WebKit — во временной папке, не в проекте |

## Технические правила премиального уровня

- **Прокрутка родная.** Без ScrollSmoother, `normalizeScroll` и `preventDefault` на wheel/touch. Закрепление сцен — CSS `position: sticky`; на iOS — не `pin`.
- **Анимировать только `transform` и `opacity`.** Не анимировать живой `filter: blur()` на больших слоях — заранее размытые изображения. Тени переключать, а не анимировать.
- **Видео по прокрутке** — покадрово на `<canvas>`:
  - холст — по фактическому размеру сцены (ResizeObserver) с `devicePixelRatio` до 3;
  - `imageSmoothingQuality = 'high'`;
  - без смешивания кадров по умолчанию;
  - в памяти держать ограниченное число декодированных кадров.
- **`prefers-reduced-motion` и Save-Data:** библиотеки не грузить, видео не запускать, оставить статичный кадр и весь текст.
- **Изображения:**
  - WebP или AVIF через `ffmpeg` (`libwebp`, `libaom-av1 -still-picture 1`) или Pillow; `sharp` — через `npx` при необходимости;
  - качество — по задаче: для кино-кадров q≥88 или без потерь.
- **Three.js / WebGL** — только когда 3D действительно нужен (npm `three`, MIT), с резервным статичным кадром. 3D-конструктор — FORMIQ, движок не дублировать.
- **Проверка перед показом владельцу:**
  1. Chromium + WebKit, телефон 390 и 320, компьютер 1440;
  2. замер LCP, CLS и частоты кадров при прокрутке;
  3. визуальная проверка по снимкам экрана, а не только функциональные тесты.

  Реальный iPhone — финальная проверка владельца.
- **Ориентиры качества:** Awwwards, Apple, Poliform, Minotti. Одно сильное движение на экран, сдержанная типографика, свет сверху справа, реальные фотографии работ.
